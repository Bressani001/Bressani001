CENTRAL ELETROMIDIA NOC v6 — COMO USAR
========================================

1. Extraia o ZIP inteiro para uma pasta.
2. NÃO mova somente o index.html: ele depende de catalog.js, machine_details.js,
   point_details.js, whatsapp.js e da pasta media/ na mesma estrutura.
3. Abra index.html no Chrome ou Edge atualizado.
4. Use a busca global ou as áreas Máquinas, Pontos, WhatsApp, Eventos,
   Ativos/Chamados, Grupos e Integridade.

BUSCA
-----
A pesquisa aceita texto parcial, termos fora de ordem e filtros.
Exemplos típicos:
  39787
  redsalvador
  recife
  grupo:manutencao
  autor:5511
  evento:outage
  asset:082209
  ticket:1856343
  os:linux
  praca:BA
  ip:179.246
  fonte:whatsapp
  midia:sim
  vinculo:alto

POLÍTICA DE CONFIANÇA
---------------------
O sistema não força ligação ambígua.
- ALTA: identificador/nome/IP/código único ou contexto citado determinístico.
- MÉDIA: nome de ponto por combinação distintiva validada.
- CONTEXTO: resposta curta em até 30 min ligada a um único contexto anterior.
- AMBÍGUA: fica sem vínculo automático para revisão humana.

SENHAS / SISTEMA OPERACIONAL
----------------------------
Regra operacional preservada:
- “Senha Padrão” => Linux
- senha específica => Windows
- senha ausente => não deduzir
As planilhas de origem não trazem as senhas. Senhas cadastradas no sistema ficam
em armazenamento local do navegador, sem inventar ou sobrescrever a fonte.

ÚLTIMA ATUALIZAÇÃO
------------------
O campo estruturado “Última Atualização” permanece ignorado, conforme solicitado.
Se a expressão aparecer dentro de uma mensagem original do WhatsApp, o texto bruto
é preservado como evidência, sem virar campo estruturado da máquina.

BACKUP
------
Faça backup dos dados locais (senhas, notas e favoritos) pela própria interface
quando disponível. Não trate localStorage como cópia única de informação crítica.

FUTURO SLACK
------------
A arquitetura já reserva Slack como outra fonte de mensagens. O modelo previsto é:
canal/thread/mensagem -> mensagem normalizada -> identificação de entidade ->
ponto/máquina/evento/ativo/chamado, preservando a origem e a confiança do vínculo.
