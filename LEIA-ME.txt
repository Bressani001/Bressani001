PRISMA FLOW V13 - NOC COMMAND CENTER
====================================

BUILD
-----
13.0.0-FINAL-NOC-20261113

COMO ABRIR
----------
1. Extraia o ZIP.
2. Abra a pasta extraída.
3. Dê dois cliques em:

   ABRIR_PRISMA.bat

Não existe montagem.
Não precisa PowerShell.
Não precisa apontar para a V11.
Não precisa instalar Leaflet ou biblioteca de Excel.
A base operacional já vem embutida.

O QUE MUDOU NA V13
------------------
- identidade PRISMA refeita com logo/branding;
- menu reorganizado por tarefa, com recursos avançados em "Mais ferramentas";
- menu recolhível;
- dashboard operacional com busca como ação principal;
- busca preditiva no topo;
- busca global com filtros simples e ações direto no resultado;
- mapa reconstruído como workspace: lista lateral + pesquisa + foco + popup + Google Maps + Operações;
- Ponto 360º reorganizado para mostrar identidade, próxima ação e relações rapidamente;
- Roteador NOC em fluxo de 3 etapas;
- importador inteligente com arrastar e soltar;
- importador continua detectando cabeçalho, melhor aba, significado de coluna e diferenças;
- atalhos de teclado;
- menos telas competindo visualmente sem remover nenhuma função antiga.

ATALHOS
-------
Ctrl + K  -> busca preditiva do topo
/         -> abre Busca Global
Alt + H   -> Visão geral
Alt + B   -> Busca
Alt + M   -> Mapa
Alt + T   -> Meu Turno
Alt + R   -> Roteador
Alt + I   -> Importar

MAPA
----
O mapa mostra apenas pontos com coordenada real válida.

Modos:
- Ruas;
- Satélite;
- Claro;
- Sem fundo.

A lista lateral acompanha a busca ou a área visível.
Clique num ponto para focar.
O popup permite abrir o cadastro, Operações e Google Maps.

Sem internet, o PRISMA continua funcionando e o mapa usa automaticamente "Sem fundo".

IMPORTADOR
----------
Aceita:
- XLSX;
- XLS;
- CSV;
- TXT tabular;
- JSON.

Pode arrastar o arquivo para a tela.

O PRISMA:
1. procura o cabeçalho;
2. analisa as abas;
3. interpreta colunas por nome + conteúdo;
4. mostra mapeamento;
5. mostra novos / alterados / iguais / duplicados / inválidos;
6. mantém a linha original;
7. preserva colunas desconhecidas;
8. permite corrigir;
9. aprende mapeamentos;
10. permite pausar, reativar ou excluir o overlay.

DADOS LOCAIS
------------
Tarefas, favoritos, correções, importações, modelos, notas, senhas e preferências
continuam no IndexedDB local do PRISMA.

A base embutida nunca é sobrescrita.
