My background combines hands-on infrastructure and operational experience with software engineering, allowing me to understand systems from both sides: **the people operating them and the code running behind them**.

Today, my main interests are:

I enjoy understanding how things work, finding what is inefficient and building better ways to solve the problem.

## 🚀 What I'm currently working on

### 🏃 Parkour Hub

I'm currently developing **Parkour Hub**, a platform focused on the parkour community.

The project is being designed to support features such as:

- User profiles
- Social posts
- Training spots
- Events
- Groups
- Gyms
- Community interactions
- Maps
- Direct messages
- Parkour news and content

The backend follows a modular architecture using:

`Controller → Service → Repository`

Main technologies:

`Node.js • TypeScript • Express • Prisma • PostgreSQL • Zod • JWT • Pino • Swagger`
